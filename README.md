# Good Samaritan

## Title
A crowd-sourced mobile safety app for KW students. 

## Project Description
Good Samaritan is a mobile safety app designed specifically for university students in the Kitchener-Waterloo region. It solves the problem of safety confidence when commuting alone by providing location-based safety alerts, an interactive map of safe and unsafe zones, and quick-access emergency contacts all crowd sourced from user inputs. It empowers students to confidently navigate campus and city spaces, especially during late-night commutes and social events.

## Getting Started
It is assumed that android studio is installed with AGP > 8.2. 

### Dev Build Installation
1. Clone the repository on main
2. Add the keys for secrets.properties in the root directory
3. Add a `google-services.json` file under the `/app` directory
> For 1, and 2, please email us and we will provide these files as they provide access to all the APIs, as per best practices we cannot push them to the commit history
> Google Drive with secret files: https://drive.google.com/drive/folders/1HtOeiT9LoMBpvPQbje34uYb5zLACu-t-?usp=sharing 
4. Run `gradle build`
5. In Android studio, click 'run app' for it to automatically run the gradle build and load it into the emulator.

### Production Build Installation
1. Use your android phone browser
2. Make sure [Install Unknown Apps](https://www.wikihow.com/Install-APK-Files-on-Android) is enabled - since our app has not been released on play store
3. Go to the latest [release notes](https://git.uwaterloo.ca/j25zhu/good-samaritan/-/wikis/Release-notes)
4. Click on the google drive link which has the installer image
5. Download the app-release.apk
6. Your should be prompted to install the app from the phone
